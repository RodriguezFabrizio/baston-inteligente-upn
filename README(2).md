
🦯 Bastón Inteligente con Asistencia de IA y IoT

Proyecto desarrollado para el curso de ingeniería en la **Universidad Privada del Norte (UPN)**. Consiste en un sistema de asistencia para personas con discapacidad visual basado en una arquitectura Edge-Cloud.

## 🚀 Características Principales
- **Detección de Obstáculos:** Sensor ultrasónico HC-SR04 integrado con el ESP32 para alertas locales de proximidad.
- **Visión Artificial:** Transmisión de video desde el ESP32-CAM y procesamiento mediante **YOLOv8** para la clasificación de objetos y obstáculos aéreos.
- **Conectividad IoT:** Protocolo **MQTT** para la comunicación en tiempo real con baja latencia (~42 ms).
- **Aplicación Móvil:** Dashboard desarrollado en **Flutter** para el monitoreo del estado del bastón, alertas y visualización de telemetría.

## 🛠️ Stack Tecnológico
- **Hardware:** ESP32, ESP32-CAM, Sensor Ultrasónico HC-SR04, Batería 18650.
- **Software Embebido:** Arduino IDE (C++).
- **Inteligencia Artificial:** Python, YOLOv8.
- **App Móvil:** Flutter (Dart).
